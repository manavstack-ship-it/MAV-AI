# Python Variables

Variables are used to store data in memory.

A variable is created when a value is assigned to it.

Python is dynamically typed, so you do not need to declare a data type.

Example:
x = 10

name = "Manav"

price = 99.99

Python variable names are case-sensitive.

Valid variable names can contain letters, numbers, and underscores.

A variable cannot start with a number.

Meaningful variable names improve code readability.

Multiple variables can be assigned in one line.

Example:
a, b, c = 1, 2, 3

Python supports multiple data types such as int, float, string, boolean, list, tuple, dictionary, and set.

Use descriptive names instead of single letters whenever possible.

Variables can be updated anytime by assigning a new value.

The type() function is used to check the data type of a variable.

Variables make programs flexible and reusable.
