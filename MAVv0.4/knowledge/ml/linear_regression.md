# Linear Regression

Linear Regression predicts continuous numerical values.

It is a supervised machine learning algorithm.

The relationship between variables is assumed to be linear.

Equation:

y = mx + c

m represents the slope.

c represents the intercept.

The algorithm minimizes prediction error.

Training involves finding the best values of m and c.

Gradient Descent is commonly used for optimization.

Evaluation metrics include MAE, MSE, RMSE, and R² Score.

Linear Regression is simple and interpretable.

It performs well on linear datasets.

It struggles with nonlinear relationships.

Feature scaling can improve training speed.

Linear Regression is widely used for prediction problems.
