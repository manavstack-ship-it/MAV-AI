# Embeddings

Embeddings convert text into numerical vectors.

Vectors represent semantic meaning.

Similar sentences produce similar vectors.

Embeddings enable semantic search.

Embeddings are generated using embedding models.

Every document chunk has its own embedding.

Questions are also converted into embeddings.

Similarity is measured using vector distance.

Cosine similarity is commonly used.

Embeddings allow searching by meaning instead of exact words.

Embedding models are different from language models.

Embeddings are stored inside vector databases.

Embeddings improve retrieval quality.

Modern RAG systems rely heavily on embeddings.

Accurate embeddings lead to better search results.
