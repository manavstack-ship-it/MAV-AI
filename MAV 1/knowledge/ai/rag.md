# Retrieval Augmented Generation

RAG stands for Retrieval Augmented Generation.

It combines information retrieval with language generation.

RAG allows language models to use external knowledge.

Documents are first converted into embeddings.

Embeddings capture semantic meaning.

Embeddings are stored in a vector database.

When a user asks a question, the question is embedded.

The vector database searches for similar embeddings.

Relevant document chunks are retrieved.

The retrieved chunks become context.

The LLM receives both the context and the user's question.

The model generates an answer using the retrieved information.

RAG reduces hallucinations.

It enables AI assistants to answer questions from private documents.

RAG is widely used in enterprise AI systems.
