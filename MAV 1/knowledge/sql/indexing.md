# SQL Indexing

Indexes improve database query performance.

An index works similarly to a book index.

Without indexes, databases perform full table scans.

Indexes reduce search time.

Primary keys automatically create indexes.

Unique constraints also create indexes.

Too many indexes can slow INSERT and UPDATE operations.

Indexes consume additional storage.

B-Tree indexes are commonly used.

Hash indexes are useful for exact lookups.

Composite indexes contain multiple columns.

Database administrators optimize indexes based on query patterns.

Proper indexing improves application performance.

Analyze slow queries before creating indexes.

Index only columns frequently used in WHERE, JOIN, and ORDER BY clauses.
