# Gradient Descent

Gradient Descent is an optimization algorithm.

It minimizes the loss function.

The algorithm updates model parameters iteratively.

The update formula is:

θ = θ − α × gradient

θ represents model parameters.

α is the learning rate.

A small learning rate leads to slow learning.

A large learning rate may overshoot the minimum.

The objective is to minimize prediction error.

Gradient Descent repeats until convergence.

Types include Batch Gradient Descent.

Stochastic Gradient Descent updates after every sample.

Mini Batch Gradient Descent uses small batches.

Gradient Descent is widely used in deep learning.

Choosing the correct learning rate is very important.
