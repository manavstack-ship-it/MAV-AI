# Object Oriented Programming

Object Oriented Programming is known as OOP.

OOP organizes code using classes and objects.

A class is a blueprint.

An object is an instance of a class.

Classes contain attributes and methods.

The __init__() method initializes an object.

The self keyword refers to the current object.

Encapsulation hides internal implementation details.

Inheritance allows one class to inherit another class.

Polymorphism allows different classes to use the same method name.

Abstraction hides unnecessary implementation details.

OOP improves code reusability.

OOP makes large applications easier to maintain.

Python supports multiple inheritance.

Real-world examples include Student, Car, BankAccount, and Employee classes.
