# Python Functions

Functions are reusable blocks of code.

They help avoid repetition.

Functions improve code organization.

Functions are defined using the def keyword.

Example:

def greet(name):
    return "Hello " + name

Functions can accept parameters.

Functions may return a value using the return keyword.

If no return statement is present, Python returns None.

Functions can call other functions.

Built-in functions include print(), len(), input(), and range().

Lambda functions are anonymous one-line functions.

Recursive functions call themselves.

Functions improve readability and maintainability.

Breaking large programs into smaller functions makes debugging easier.

Good function names describe what the function does.

Functions follow the DRY principle (Don't Repeat Yourself).
